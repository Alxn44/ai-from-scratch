# docs

Background reading. Nothing here is loaded by code, and nothing here is
generated — these are the written record of decisions and their reasons.

The four documents that stayed at the repository root did so because they are
entry points, not background: `README.md`, `CLAUDE.md`, `RUNBOOK.md` (what
command to run for what) and `ONTOLOGY.md` (generated by `pnpm ontology`).

| Document | What it is for |
|---|---|
| [ARCHITECTURE.md](ARCHITECTURE.md) | The service split, the transport rule, and why orchestration is a library rather than a service. |
| [architecture-animation.html](architecture-animation.html) | Interactive animated version of the architecture: the 4 happy-path scenarios and the 4 blocked attacks, step by step. Open in a browser, no server needed. |
| [SECURITY-AUDIT.md](SECURITY-AUDIT.md) | 30 findings with a proof column separating what was verified live from what was read. Its gate table is a dated snapshot and is deliberately not edited afterwards. |
| [MIGRATION.md](MIGRATION.md) | The JavaScript to Python and JavaScript to TypeScript moves, including corrections to earlier claims made in this same file. |
| [NAMING.md](NAMING.md) | The rename contract. Its "now → becomes" tables keep the OLD names on the left on purpose — do not "fix" them. |
| [PLATFORM.md](PLATFORM.md) | What the platform does, screen by screen. |
| [REGIONS.md](REGIONS.md) | Regional pricing and language. |

| [HANDOFF-IOS-2026-08-28.md](HANDOFF-IOS-2026-08-28.md) | What a designer and an iOS engineer need to build the native app: the design tokens that are already Apple's system colours, the API contract, the paywall rule, and the three decisions — App Store in-app purchase, the 12-hour session, the chat without streaming — that change the design if they are answered afterwards. Dated for the same reason as the one above. |

The three prompt files (`ARCHITECTURE-DIAGRAM-PROMPT.md`,
`DEFENSE-DIAGRAM-PROMPT.md`, `ARCHITECTURE-EXPLAIN-PROMPT.md`) are not in the
table because they are inputs to a model, not background reading; each one states
the facts it was built from so an output that contradicts them can be spotted.
The first two ask for a picture; `ARCHITECTURE-EXPLAIN-PROMPT.md` asks for the
prose explanation, covers the server and the deploy pipeline, and its section 5
lists the places where the other documents in this repository currently disagree
with the running system.

Two documents describe things that changed after they were written, and say so
in place rather than being quietly rewritten: `SECURITY-AUDIT.md`'s verification
table records the numbers and command names that were true when they were
measured, with a note listing what has since moved; and `MIGRATION.md` corrects
three of its own earlier claims instead of deleting them. A document that
silently updates its history stops being evidence.
