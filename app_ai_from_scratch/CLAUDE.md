# IA desde cero — the platform

Bilingual course platform: 12 lessons, 36 labs, 12 ranks, an agentic chat that
can only ever see the asking user's own data.

**Read [RUNBOOK.md](RUNBOOK.md) first.** It maps "do this" to the exact command.
Do not invent a command for a routine task — if it is routine it is in there, and
if it is not, add it once it has been done twice.

The one command worth memorising: **`pnpm verify`** — every gate, one verdict,
about 12 seconds.

Four documents live at the root because they are entry points: this file,
`README.md`, `RUNBOOK.md`, and `ONTOLOGY.md` (generated — run `pnpm ontology`,
never edit it). Everything else is background reading in
[docs/](docs/README.md), which has an index saying what each one is for.

## Shape

| Directory | Stack | Owns |
|---|---|---|
| `api/` | Node 22 + TypeScript, compiled with **tsgo** | HTTP, sessions, the 37 agent tools, the Postgres job queue |
| `ai/` | Python + FastAPI, **uv** | The agent loop, model providers, and the ontology — the source of truth |
| `web/` | Astro | The lessons, labs, chat, and the 12 animated lesson scenes |
| `queue/` | Go + Fiber | The RabbitMQ topology between services |
| `scripts/` | Node + bash | Anything spanning more than one service |

Postgres (Prisma owns the schema, `pg` runs the queries — no query engine in the
image). Prisma **cannot express CHECK constraints**: three of them are re-added
by hand in the baseline migration, and `db:drift` is what notices if they vanish.

Tools exist in **both** backends on purpose: the platform is agentic from either
entry point.

## The ontology, and why it is the centre

The ontology is **data**, and a graph proves things over that data. It is not
prose describing what the code does — that was v2, and it drifted.

Four obligations, all proved by `pnpm prove`:

- **P1** no `jamas` column is returned by any tool
- **P2** a tool reaching `propio` columns declares its scope
- **P3** no argument can express another person
- **P4** no `de_pago` column is returned without declaring `verifica_compra`

**Two orthogonal axes, and collapsing them is the bug that already happened.**
`clase` (`publico|propio|agregado|jamas`) answers *whose data is this* — privacy.
`muro` (`gratis|de_pago`) answers *who paid to read it* — entitlement. With one
axis the paywall rule was inexpressible, so the proof stayed green while the paid
corpus walked out. P4 exists because of that.

Edit `ai/src/course_ai/ontology/data.py`. Never the artefact
(`api/src/ontologia.json`), never `ONTOLOGY.md` — both are generated.

## House rules

These are not style preferences. Each one is a failure that happened here.

1. **Fail closed, loudly.** A guard that approves what it never inspected is
   worse than no guard, because the review passes. `forbiddenColumns` throws for
   an undeclared table instead of returning `[]`.
2. **Read exit codes directly, never through a pipe.** `cmd | tail` reports
   `tail`'s status. That produced one confident, wrong "exit 0" here.
3. **Never skip silently.** A suite that prints "skipped" and exits 0 is
   indistinguishable from a pass. If a check cannot run, it failed.
4. **Generate from the source of truth, never a copy.** The tool catalogue is
   read by *importing* the registry; a regex over its source broke twice, and
   each time the guard went dark while everything stayed green.
5. **No forgeable defaults.** No default secret, no default password, no default
   DSN outside development. Compare secrets in constant time.
6. **Don't touch what isn't yours.** `pnpm dev` identifies a process by its
   working directory before killing it. Something on our port may belong to
   another project.
7. **Measure, don't assume.** Claims about performance, coverage or counts get a
   number from a real run, or they do not get made.

## Language

Everything is **English** — files, folders, functions, comments, identifiers.

Deliberate exceptions, because renaming them breaks two services at once:

- **wire values**: route paths (`/api/...`, `/salud`, `/ontologia/*`), the
  `x-ia-secreto` / `x-ia-sesion` headers, `IA_SECRETO`, and response keys the
  front end reads (`respuesta`, `traza`, `paso`, …);
- **`error:` codes** the UI switches on (`requiere_compra`, `no_session`, …);
- **ontology data values**: `publico`, `propio`, `agregado`, `jamas`, `gratis`,
  `de_pago`, `sesion`, and the artefact's keys (`clases`, `prohibidas`, `muros`);
- **`api/src/ontologia.json`** keeps its filename — it is generated by Python and
  read by Node, so renaming it is a coordinated change;
- **product copy** rendered to students stays Spanish. Translating it would ship
  English text into a Spanish UI, which is a content decision, not a rename.

## Content voice

Plain spoken language, short sentences, no jargon without an instant
translation. The AI speaks in the first person inside examples. Honest claims
only — never an invented statistic. One concept per lesson.
